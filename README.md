## Run the number converter

With Python 3 installed, open Terminal at the repository root and run:

```sh
cd mission-05-numbers-data
python3 number_converter.py
```

Enter a decimal integer when prompted. For example, entering `25` produces:

```text
Binary: 0b11001
Hexadecimal: 0x19
```
