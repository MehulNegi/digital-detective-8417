## 1. Task / objective

Use input, processing, output and storage (IPOS) to explain a computer activity. Identify hardware, software and everyday computer-based systems.

## 2. Work completed

### Task 1.1 — IPOS

I typed a short note in TextEdit, saved it as `ipos-test.txt`, and reopened it to check that the sentence was still there.

| Stage | What happened? | Hardware or component |
|---|---|---|
| Input | I pressed the keys to type a sentence. | Keyboard |
| Processing | The processor ran the instructions that handled my key presses. The text I was editing was held in memory. | CPU and RAM |
| Output | The letters appeared on the screen as I typed. | Display |
| Storage | I saved the note as a file and could reopen it after closing the document. | SSD |
